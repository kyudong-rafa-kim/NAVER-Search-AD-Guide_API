1 Prerequisites & Access Request

⚠️ The GFA API can only be used after obtaining access through an official partner (agency).
It is currently in a beta period where only some accounts can apply, and "usage applications are allowed only for official partners." API access is granted after approval by the administrator (Naver).

STEP 1. Register an Application in Naver Developers

  1. Naver Developers (developers.naver.com) → [Application] → [Register Application]
  2. After agreeing to the terms, complete phone verification and enter your company name
  3. Be sure to select "Naver Login" under the APIs to use
⚠️ When using the Performance DA API, the information-provision (personal data) items set in the Naver Login API, such as name and email, are not needed. Selecting information-provision items may restrict use of your Client ID.

STEP 2. Issue Client ID / Client Secret

Once application registration is complete, a Client ID and Client Secret are issued.

STEP 3. Apply to Use the GFA API

  1. Copy the Client ID value from your registered application
  2. Access the Naver Performance Display Ads site → Primary management account → Settings → API Management menu
  3. Register the Client ID under [Apply for API Use] → access is granted after administrator approval

STEP 4. Connect Naver Login (Issue Access Token)

Through Naver ID login (OAuth 2.0) integration, you obtain the access token to use for API calls.

2 Scope & Limitations

🆕 As of August 26, 2026, ADVoost Shopping (PMAX) campaigns can also be operated via the API.
The existing Campaign API now supports create, read, update, ON/OFF, and delete for ADVoost Shopping campaigns, along with asset-group-level performance retrieval. GFA and ADVoost Shopping can now be run through a single API system.

What You Can Do with the API

  • Query ad account and manager account lists/details (including permission levels)
  • Create, update, query, delete, and toggle ON/OFF campaigns, ad groups (adSet), and creatives
  • Creative creation API — image banner / native image / collection / video (new in 2026.05.27)
  • Image and video upload API (new in 2026.05.27)
  • ADVoost Shopping (PMAX) campaign creation and management (new in 2026.08.26)
  • Performance retrieval — past / real-time / conversion, across the creative hierarchy and the asset group hierarchy
  • Manage audience targets (customer files)

What the API Still Cannot Do

Settlement (billing) amounts, tax invoicesNot supportedAd management platform (UI)

4 Authentication

Authentication method: A Naver Login-based OAuth 2.0 Access Token. Include a Bearer token in the Authorization header of every request.

Required HTTP Headers

HeaderDescriptionRequired
AuthorizationBearer {access token} formatAlways required
AccessManagerAccountNoManagement account number — needed only when making requests to an ad account under a management accountConditional

If you are a direct member of the ad account, AccessManagerAccountNo is not needed.

Request Example — Query Campaigns of an Ad Account Under a Management Account

bash / curl 
curl -X GET 'https://openapi.naver.com/v1/ad-api/1.0/adAccounts/456/campaigns' \
  -H 'AccessManagerAccountNo: 123' \
  -H 'Authorization: Bearer {access token}'

# Query the campaign list of ad account (456) under management account (123)

5 Account API

Available Functions

  • Query my ad account list: Query the list of ad accounts where you have been granted a permission level (AccountRole) as a direct member (paging supported)
  • Query ad account information: Query the detailed information of a specific ad account (indirect access possible through a parent management account)

Image & Video Upload API (new in 2026.05.27)

Upload the files to be used in a creative first, then pass the returned ID to the creative creation API as imageNo, videoNo, or thumbnailImageNo.

Endpoint (POST)Purpose
/adAccounts/{adAccountNo}/creatives/imageImage upload
/adAccounts/{adAccountNo}/creatives/videoVideo upload (callback supported)

7 Performance API

Performance Hierarchies

Hierarchy 
Creative hierarchy   : Ad account → Campaign → Ad group → Creative
Asset group hierarchy: Ad account → Campaign → Asset group   ← ADVoost Shopping (PMAX), added 2026.08.26

Results are aggregated at a level below the queried unit. (e.g., past performance of a campaign is aggregated by ad group, creative, or asset group.)

Three Retrieval Types

TypePathKey Parameters
Past performance/performance/past/{aggregationType}startDate, endDate, timeUnit (daily/hourly), limit, next
Real-time performance/performance/realtime/creatives
/performance/realtime/assetGroups		targetDate (today/yesterday), since, timeUnit
Conversion performance/performance/conversion/past/…
/performance/conversion/realtime/…		Same as above + conversion metrics

Past performance aggregationType: campaigns · adSets · creatives · assetGroups (added 2026.08.26)

For real-time performance, pass the until value from the response as since in the next request for incremental retrieval.

Extracting Spend by Ad Account

There is no endpoint that returns an account-level total directly. Because adAccounts is not available as an aggregationType, the standard approach is to call the ad account endpoint at campaign level and sum sales.

bash / curl 
# 1) List my ad accounts
curl -X GET 'https://openapi.naver.com/v1/ad-api/1.0/adAccounts' \
  -H 'Authorization: Bearer {access token}'

# 2) Query past performance per account, by campaign and by day → sum rows[].sales
curl -X GET 'https://openapi.naver.com/v1/ad-api/1.0/adAccounts/456/performance/past/campaigns?startDate=2026-09-01&endDate=2026-09-10&timeUnit=daily' \
  -H 'AccessManagerAccountNo: 123' \
  -H 'Authorization: Bearer {access token}'

# 3) For multiple accounts, iterate the list from 1) and repeat 2)
⚠️ Performance-based spend (sales) may differ from settlement/billing amounts. No API is provided for settlement data such as account balance, top-ups, refunds, or tax invoices. Settlement amounts must be checked in the ad management platform (UI).

For detailed request/response specs, refer to the Performance API specification in the official docs.

9 Operating Notes & FAQ

Frequently Asked Questions

  • Authentication errors: First check access token expiration/validity and the timing of service terms agreement
  • Response field meanings: Check the response field descriptions in each API menu
  • Manager account permissions: Use the AccessManagerAccountNo header when making requests to ad accounts under a management account
  • Can I extract spend per ad account? Yes. There is no account-level total endpoint, so you must query at campaign level and sum sales. An API for settlement/billing amounts is still not provided.
  • Does the API support ADVoost Shopping? Yes. Since August 26, 2026, campaign creation/management (PMAX) and asset-group-level performance retrieval are supported. Asset groups themselves can only be created or edited in the UI.
