1 사전 준비 & 권한 신청

⚠️ GFA API는 공식 파트너(대행사)를 통해 권한을 받아야 사용할 수 있습니다.
현재 베타 기간으로 일부 계정만 신청 가능하며, "공식 파트너에 한해 사용 신청"이 허용됩니다. 관리자(네이버) 승인 후 API 권한이 부여됩니다.

STEP 1. 네이버 개발자 센터 애플리케이션 등록

  1. 네이버 개발자 센터(developers.naver.com) → [Application] → [애플리케이션 등록]
  2. 이용약관 동의 후 휴대폰 인증, 회사 이름 입력
  3. 사용 API에서 '네이버 로그인'을 반드시 선택
⚠️ 성과형 DA API 이용 시 네이버 로그인 API에서 설정한 이름·이메일 등 제공 정보(개인정보) 항목은 불필요합니다. 제공 정보 항목을 선택하면 Client ID 사용이 제한될 수 있습니다.

STEP 2. Client ID / Client Secret 발급

애플리케이션 등록을 완료하면 Client ID와 Client Secret이 발급됩니다.

STEP 3. GFA API 사용 신청

  1. 등록한 애플리케이션에서 Client ID 값을 복사
  2. 네이버 성과형 디스플레이 광고 사이트 접속 → 대표 관리 계정 → 설정 → API 관리 메뉴
  3. [API 사용 신청]에서 Client ID를 등록 → 관리자 승인 후 권한 부여

STEP 4. 네이버 로그인 연동 (액세스 토큰 발급)

네이버 아이디 로그인(OAuth 2.0) 연동을 통해 API 호출에 사용할 액세스 토큰을 발급받습니다.

2 지원 범위 & 제약사항

🆕 2026년 8월 26일부터 ADVoost 쇼핑(PMAX) 캠페인도 API로 운영할 수 있습니다.
기존 캠페인 API에서 ADVoost 쇼핑 캠페인의 생성·조회·수정·ON/OFF·삭제가 지원되며, 애셋 그룹 단위 성과 조회도 함께 제공됩니다. 이로써 GFA와 ADVoost 쇼핑을 하나의 API 체계로 운영할 수 있습니다.

API로 할 수 있는 것

  • 광고 계정 · 관리 계정 목록/정보 조회 (권한 레벨 포함)
  • 캠페인 · 광고그룹(adSet) · 소재(creative) 생성·수정·조회·삭제·ON/OFF
  • 광고 소재 생성 API — 이미지 배너 / 네이티브 이미지 / 컬렉션 / 동영상 (2026.05.27 신규)
  • 이미지·동영상 업로드 API (2026.05.27 신규)
  • ADVoost 쇼핑(PMAX) 캠페인 생성·관리 (2026.08.26 신규)
  • 성과 조회 — 과거 / 실시간 / 전환, 소재 계층 + 애셋 그룹 계층
  • 잠재고객 타겟(고객 파일) 관리

아직 API로 할 수 없는 것

성과 집계 단위 adAccounts미지원 — 최소 집계 단위는 캠페인캠페인 단위 조회 후 합산
애셋 그룹 및 하위 요소 생성·수정미지원 — 성과 조회만 가능광고 관리 플랫폼(UI)

4 인증 (Authentication)

인증 방식: 네이버 로그인 기반 OAuth 2.0 Access Token. 모든 요청의 Authorization 헤더에 Bearer 토큰을 포함합니다.

필수 HTTP 헤더

헤더설명필수
AuthorizationBearer {액세스 토큰} 형식항상 필수
AccessManagerAccountNo관리계정 번호 — 관리계정 하위 광고계정에 요청할 때만 필요조건부

광고계정의 직접 멤버인 경우 AccessManagerAccountNo는 불필요합니다.

요청 예시 — 관리계정 하위 광고계정의 캠페인 조회

bash / curl 
curl -X GET 'https://openapi.naver.com/v1/ad-api/1.0/adAccounts/456/campaigns' \
  -H 'AccessManagerAccountNo: 123' \
  -H 'Authorization: Bearer {액세스 토큰}'

# 관리계정(123) 하위의 광고계정(456) 캠페인 목록 조회

5 광고 계정 API (Account API)

제공 기능

  • 내 광고 계정 목록 조회: 직접 멤버로 권한 레벨(AccountRole)을 부여받은 광고 계정 목록 조회 (페이징 지원)
  • 광고 계정 정보 조회: 특정 광고 계정의 상세 정보 조회 (상위 관리 계정을 통한 간접 접근 가능)

6 광고 구조 API (Ad API)

계층 구조

구조도 
광고 계정 (adAccount)
  └── 캠페인 (campaign)        ← 광고 목적(objective) 단위
        └── 광고그룹 (adSet)    ← 타겟팅 / 예산 / 게재위치
              └── 소재 (creative)

캠페인 생성 — 사전 조회 4가지

캠페인을 생성하기 전, 목적에 따라 아래 ID를 먼저 조회해 두어야 합니다.

사전 조회 API획득 값
대표 URL 목록 APIurlNo (대표 URL ID)
브랜드 목록 APIbrandNo (브랜드 ID)
전환 추적 대상 목록 APIconversionUrlNo (전환 ID)
카탈로그 목록 APIcatalogId (카탈로그 ID)

이후 [캠페인 만들기 API]로 캠페인을 생성합니다. 캠페인 예산 최적화(CBO) 옵션 변경 API도 지원됩니다.

캠페인 목적 (CampaignObjective)

캠페인 목적에 따라 필수 요청 파라미터가 달라집니다.

enum 값의미
CONVERSION웹사이트 전환
WEB_SITE_TRAFFIC인지도 및 트래픽
INSTALL_APP앱 전환
WATCH_VIDEO동영상 조회
CATALOG카탈로그 판매
SHOPPING쇼핑 프로모션
LEAD잠재고객 확보 — 전환 추적 대상(conversionUrlNo) 미사용
PMAXADVoost 쇼핑 (2026.08.26 신규)
⚠️ SHOPPING(쇼핑 프로모션)과 PMAX(ADVoost 쇼핑)는 서로 다른 캠페인 목적입니다. ADVoost 쇼핑 캠페인은 PMAX를 사용하며 예산 입력·성과 조회 방식도 다릅니다. 아래 ADVoost 쇼핑(PMAX) 캠페인을 참고하세요.

소재 타입 (CreativeType)

  • SINGLE_IMAGE (네이티브 이미지) · MULTIPLE_IMAGE (컬렉션) · SINGLE_VIDEO (동영상) · IMAGE_BANNER (이미지 배너) · CATALOG (카탈로그)

소재 생성 API (2026.05.27 신규)

그동안 광고 관리 플랫폼(UI)에서만 가능했던 소재 생성을 API로 직접 수행할 수 있습니다. 소재 타입별로 엔드포인트가 나뉩니다.

엔드포인트 (POST)소재 타입
/adAccounts/{adAccountNo}/creatives/IMAGE_BANNER이미지 배너 (스마트채널 / 모바일DA)
/adAccounts/{adAccountNo}/creatives/SINGLE_IMAGE네이티브 이미지 (피드형 / 배너형)
/adAccounts/{adAccountNo}/creatives/MULTIPLE_IMAGE이미지 컬렉션
/adAccounts/{adAccountNo}/creatives/MULTIPLE_IMAGE_WITH_VIDEO동영상 컬렉션
/adAccounts/{adAccountNo}/creatives/NATIVE_VIDEO동영상 (피드형 / 배너형)
/adAccounts/{adAccountNo}/creatives/INSTREAM_VIDEO동영상 (인스트림형)

지원 템플릿(creativeTemplateCode) 예시: NATIVE_SINGLE_IMAGE_V2, NATIVE_SINGLE_IMAGE_PC, FEED_SINGLE_IMAGE, FEED_SINGLE_IMAGE_SQUARE, FEED_SINGLE_IMAGE_2TO3, NATIVE_SINGLE_IMAGE_COMMUNICATION, NATIVE_SINGLE_VIDEO, FEED_SHORTFORM_VIDEO, FEED_SINGLE_VIDEO, INSTREAM_VIDEO

⚠️ 네이티브 이미지 · 컬렉션 · 동영상 소재를 생성하려면 사전에 광고 계정 관리 > 프로필 관리에서 프로필 등록이 필요합니다.

이미지 · 동영상 업로드 API (2026.05.27 신규)

소재 생성에 사용할 파일을 먼저 업로드하고, 응답으로 받은 ID를 소재 생성 API의 imageNo · videoNo · thumbnailImageNo 파라미터에 사용합니다.

엔드포인트 (POST)용도
/adAccounts/{adAccountNo}/creatives/image이미지 업로드
/adAccounts/{adAccountNo}/creatives/video동영상 업로드 (콜백 지원)
  • 광고 계정당 동시에 1회만 호출 가능
  • 동영상은 100MB 이내까지 업로드 가능 — 초과 시 광고 관리 플랫폼(UI)에서 직접 업로드
  • callbackUrl을 등록하면 업로드·인코딩 완료/실패 시점을 수신 가능

ADVoost 쇼핑(PMAX) 캠페인 (2026.08.26 신규)

기존 캠페인 API에서 캠페인 목적 PMAX로 ADVoost 쇼핑 캠페인의 생성 · 조회 · 수정 · ON/OFF · 삭제를 수행합니다.

항목내용
예산 입력performanceMax.budget (일 예산) — 기존 spendLimit은 사용하지 않으며 입력해도 무시됨
예산 변경캠페인 지출 한도 다중 변경 API(/campaigns/editSpendLimit)의 campaignSpendLimit 값이 performanceMax.budget에 반영
변경 제한광고 최적화 보호를 위해 캠페인당 2시간에 1회로 제한
생성 조건전환추적 설정 필수(전환 스크립트 설치 완료) + 비즈채널 승인 상태
애셋 그룹캠페인 생성 시 기본값(모든 아이템)으로 자동 생성 — 아이템 필터링 등 설정 변경은 광고시스템(UI)에서만 가능
이용 동의쇼핑상품연동·오프사이트 광고 이용동의가 필요한 경우 자동 동의 처리
⚠️ 애셋 그룹 및 하위 요소의 생성·수정 API는 제공되지 않습니다. 애셋 그룹은 성과 조회만 가능합니다 (CH 7 참고).

7 성과 조회 API (Performance API)

성과 조회 계층

조회 계층 
소재 계층      : 광고 계정 → 캠페인 → 광고 그룹 → 소재
애셋 그룹 계층 : 광고 계정 → 캠페인 → 애셋 그룹    ← ADVoost 쇼핑(PMAX), 2026.08.26 추가

조회 단위보다 하위 요소로 집계한 결과가 제공됩니다. (예: 캠페인의 과거 성과는 광고그룹·소재 또는 애셋 그룹 단위로 집계)

조회 유형 3가지

유형경로주요 파라미터
과거 성과/performance/past/{aggregationType}startDate, endDate, timeUnit(daily/hourly), limit, next
실시간 성과/performance/realtime/creatives
/performance/realtime/assetGroups		targetDate(today/yesterday), since, timeUnit
전환 성과/performance/conversion/past/…
/performance/conversion/realtime/…		위와 동일 + 전환 지표

과거 성과의 aggregationType : campaigns · adSets · creatives · assetGroups(2026.08.26 추가)

실시간 성과는 응답의 until 값을 다음 요청의 since로 사용해 증분 조회할 수 있습니다.

주요 응답 지표

필드의미
sales광고비 (소진 금액)
impCount / clickCount / vplayCount노출 수 / 클릭 수 / 동영상 재생 수
convCount / convSales전환 횟수 / 전환 매출
targetDate / hour성과 발생 일자 / 시간대 (시간별 조회 시에만 포함)
campaignNo / adSetNo / creativeNo / assetGroupNo집계 단위 ID

애셋 그룹 단위 일반 성과 조회 시 vplayCount는 항상 0으로 제공됩니다.

광고 계정별 소진 금액 추출하기

계정 단위 합계를 한 번에 돌려주는 엔드포인트는 없습니다. 집계 단위(aggregationType)에 adAccounts가 없기 때문에, 광고 계정 엔드포인트를 캠페인 단위로 호출한 뒤 sales를 합산하는 것이 표준 방식입니다.

bash / curl 
# 1) 내 광고 계정 목록 조회
curl -X GET 'https://openapi.naver.com/v1/ad-api/1.0/adAccounts' \
  -H 'Authorization: Bearer {액세스 토큰}'

# 2) 계정별 과거 성과를 캠페인 단위·일자별로 조회 → rows[].sales 합산
curl -X GET 'https://openapi.naver.com/v1/ad-api/1.0/adAccounts/456/performance/past/campaigns?startDate=2026-09-01&endDate=2026-09-10&timeUnit=daily' \
  -H 'AccessManagerAccountNo: 123' \
  -H 'Authorization: Bearer {액세스 토큰}'

# 3) 계정이 여러 개면 1)의 목록을 순회하며 2)를 반복 호출
⚠️ 성과 기준 소진액(sales)과 정산·청구 금액은 다를 수 있습니다. 계정 잔액·충전·환불, 세금계산서 등 정산 정보를 조회하는 API는 제공되지 않습니다. 정산 기준 금액은 광고 관리 플랫폼(UI)에서 확인해야 합니다.

상세 요청·응답 스펙은 공식 문서의 성과 API 명세를 참고하세요.

8 잠재고객 관리 API (Custom Target)

고객 파일 타겟

  • 광고 식별자(adid) 목록을 업로드해 고객 파일 타겟을 등록·수정, 일부 adid 추가·제거 가능
  • 등록된 고객 파일은 광고그룹의 잠재고객 타겟으로 활용
  • 콜백 URL을 등록해 유효성 검사·업로드 결과를 추적 가능
항목제한
단일 업로드 용량최대 100MB
누적 용량최대 600MB까지 추가 가능
업로드 타임아웃20초
중복 요청분석 완료 전까지 동일 adidLibraryNo 중복 요청 불가

9 운영 참고 & FAQ

자주 묻는 질문

  • 인증 오류: 액세스 토큰 만료/유효성, 서비스 이용약관 동의 시점 문제를 먼저 확인
  • 응답 필드 의미: 각 API 메뉴에서 응답 필드 설명 확인
  • 매니저 계정 권한: 관리계정 하위 광고계정 요청 시 AccessManagerAccountNo 헤더 사용
  • 계정별 소진 금액을 뽑을 수 있나요? 네. 다만 계정 단위 합계 엔드포인트가 없어 캠페인 단위로 조회한 뒤 sales를 합산해야 합니다. 정산·청구 금액을 조회하는 API는 여전히 제공되지 않습니다.
  • ADVoost 쇼핑도 API로 되나요? 네. 2026년 8월 26일부터 캠페인 생성·관리(PMAX)와 애셋 그룹 단위 성과 조회가 지원됩니다. 단, 애셋 그룹 자체의 생성·수정은 UI에서만 가능합니다.
