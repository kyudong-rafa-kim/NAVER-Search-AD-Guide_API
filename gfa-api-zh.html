1 前期准备 & 权限申请

⚠️ GFA API 需通过官方合作伙伴（代理商）获得权限后方可使用。
目前处于测试版期间，仅部分账户可申请，且仅允许「官方合作伙伴提交使用申请」。经管理员（Naver）批准后授予API权限。

STEP 1. 在Naver开发者中心注册应用

  1. Naver开发者中心（developers.naver.com） → [Application] → [应用注册]
  2. 同意使用条款后进行手机认证，输入公司名称
  3. 在使用的API中务必选择「Naver登录」
⚠️ 使用效果型DA API时，无需在Naver登录API中设置的姓名、邮箱等提供信息（个人信息）项目。若选择了提供信息项目，Client ID的使用可能会受到限制。

STEP 2. 发放 Client ID / Client Secret

完成应用注册后，将发放Client ID与Client Secret。

STEP 3. 申请使用GFA API

  1. 在已注册的应用中复制Client ID值
  2. 访问Naver效果型展示广告站点 → 代表管理账户 → 设置 → API管理菜单
  3. 在[API使用申请]中注册Client ID → 经管理员批准后授予权限

STEP 4. Naver登录联动（发放访问令牌）

通过Naver账号登录（OAuth 2.0）联动，发放用于API调用的访问令牌。

2 支持范围 & 限制事项

🆕 自2026年8月26日起，ADVoost购物（PMAX）广告系列也可通过API运营。
现有广告系列API支持ADVoost购物广告系列的创建·查询·修改·ON/OFF·删除，并同时提供资产组单位的成效查询。由此可将GFA与ADVoost购物纳入同一套API体系运营。

通过API可以做的事

  • 广告账户 · 管理账户列表/信息查询（含权限级别）
  • 广告系列 · 广告组(adSet) · 素材(creative) 的创建·修改·查询·删除·ON/OFF
  • 广告素材创建API — 图片横幅 / 原生图片 / 合集 / 视频 （2026.05.27 新增）
  • 图片·视频上传API （2026.05.27 新增）
  • ADVoost购物（PMAX）广告系列创建·管理 （2026.08.26 新增）
  • 成效查询 — 历史 / 实时 / 转化，素材层级 + 资产组层级
  • 潜在客户定向（客户文件）管理

目前API仍无法做的事

项目当前状态替代方案
广告账户余额 · 充值 · 退款查询不支持广告管理平台（UI）
结算（账单）金额 · 税务发票查询不支持广告管理平台（UI）
管理账户下全部广告账户的合并报表不支持查询广告账户列表后按账户循环调用
成效汇总单位 adAccounts不支持 — 最小汇总单位为广告系列按广告系列查询后合计
资产组及其下级要素的创建·修改不支持 — 仅可查询成效广告管理平台（UI）
超过100MB的视频上传不支持在广告管理平台（UI）中直接上传

按广告账户提取消耗金额的方法请参考 CH 7 — 按账户提取消耗金额。

3 API基础结构

Base URL

Base URL 
https://openapi.naver.com/v1/ad-api/{version}/[端点]

· v1 ：固定值
· {version} ：各API分别定义的版本（默认值 "1.0"）

广告结构术语映射

UI名称API名称说明
广告账户adAccount运营广告的最顶层账户单位
广告系列campaign广告目的(objective)单位
广告组adSet定向·预算·版位策略单位
素材creative实际展示的广告素材
资产组assetGroupADVoost购物（PMAX）广告系列的素材·商品组合单位

4 认证 (Authentication)

认证方式：基于Naver登录的OAuth 2.0 Access Token。在所有请求的Authorization头中包含Bearer令牌。

必填HTTP头

头说明必填
AuthorizationBearer {访问令牌} 格式始终必填
AccessManagerAccountNo管理账户编号 — 仅在向管理账户下属广告账户发起请求时需要条件性

若是广告账户的直接成员，则无需AccessManagerAccountNo。

请求示例 — 查询管理账户下属广告账户的广告系列

bash / curl 
curl -X GET 'https://openapi.naver.com/v1/ad-api/1.0/adAccounts/456/campaigns' \
  -H 'AccessManagerAccountNo: 123' \
  -H 'Authorization: Bearer {访问令牌}'

5 广告账户API (Account API)

提供功能

  • 查询我的广告账户列表：查询作为直接成员被授予权限级别（AccountRole）的广告账户列表（支持分页）
  • 查询广告账户信息：查询特定广告账户的详细信息（可通过上级管理账户间接访问）

6 广告结构API (Ad API)

层级结构

结构图 
广告账户 (adAccount)
  └── 广告系列 (campaign)        ← 广告目的(objective)单位
        └── 广告组 (adSet)        ← 定向 / 预算 / 版位
              └── 素材 (creative)

广告系列创建 — 4项前置查询

在创建广告系列之前，需根据目的先行查询以下ID。

前置查询API获取值
代表URL列表APIurlNo (代表URL ID)
品牌列表APIbrandNo (品牌ID)
转化追踪对象列表APIconversionUrlNo (转化ID)
目录列表APIcatalogId (目录ID)

随后通过[创建广告系列API]创建广告系列。同时支持广告系列预算优化(CBO)选项变更API。

广告系列目的 (CampaignObjective)

根据广告系列目的，必填请求参数各不相同。

enum 值含义
CONVERSION网站转化
WEB_SITE_TRAFFIC知名度及流量
INSTALL_APPApp转化
WATCH_VIDEO视频观看
CATALOG目录销售
SHOPPING购物推广
LEAD潜在客户开发 — 不使用转化追踪对象(conversionUrlNo)
PMAXADVoost购物（2026.08.26 新增）
⚠️ SHOPPING（购物推广）与PMAX（ADVoost购物）是两个不同的广告系列目的。ADVoost购物广告系列使用PMAX，其预算填写方式与成效查询路径也不同。请参考下方ADVoost购物（PMAX）广告系列。

素材类型 (CreativeType)

  • SINGLE_IMAGE (原生图片) · MULTIPLE_IMAGE (合集) · SINGLE_VIDEO (视频) · IMAGE_BANNER (图片横幅) · CATALOG (目录)

素材创建API （2026.05.27 新增）

此前只能在广告管理平台（UI）中完成的素材创建，现可通过API直接执行。不同素材类型对应不同端点。

端点 (POST)素材类型
/adAccounts/{adAccountNo}/creatives/IMAGE_BANNER图片横幅（智能频道 / 移动DA）
/adAccounts/{adAccountNo}/creatives/SINGLE_IMAGE原生图片（信息流 / 横幅）
/adAccounts/{adAccountNo}/creatives/MULTIPLE_IMAGE图片合集
/adAccounts/{adAccountNo}/creatives/MULTIPLE_IMAGE_WITH_VIDEO视频合集
/adAccounts/{adAccountNo}/creatives/NATIVE_VIDEO视频（信息流 / 横幅）
/adAccounts/{adAccountNo}/creatives/INSTREAM_VIDEO视频（插播型）

支持的模板(creativeTemplateCode)示例：NATIVE_SINGLE_IMAGE_V2、NATIVE_SINGLE_IMAGE_PC、FEED_SINGLE_IMAGE、FEED_SINGLE_IMAGE_SQUARE、FEED_SINGLE_IMAGE_2TO3、NATIVE_SINGLE_IMAGE_COMMUNICATION、NATIVE_SINGLE_VIDEO、FEED_SHORTFORM_VIDEO、FEED_SINGLE_VIDEO、INSTREAM_VIDEO

⚠️ 创建原生图片 · 合集 · 视频素材前，需先在广告账户管理 > 档案管理中注册档案(profile)。

图片 · 视频上传API （2026.05.27 新增）

先上传素材创建所需的文件，再将响应中返回的ID用作素材创建API的imageNo · videoNo · thumbnailImageNo参数。

端点 (POST)用途
/adAccounts/{adAccountNo}/creatives/image图片上传
/adAccounts/{adAccountNo}/creatives/video视频上传（支持回调）
  • 每个广告账户同时仅可调用1次
  • 视频文件最大100MB — 超出部分请在广告管理平台（UI）中直接上传
  • 注册callbackUrl后可接收上传·编码完成/失败的通知

ADVoost购物（PMAX）广告系列 （2026.08.26 新增）

在现有广告系列API中，以广告系列目的PMAX执行ADVoost购物广告系列的创建 · 查询 · 修改 · ON/OFF · 删除。

项目内容
预算填写performanceMax.budget（日预算）— 不使用原有的spendLimit，即使填写也会被忽略
预算变更广告系列支出上限批量变更API(/campaigns/editSpendLimit)的campaignSpendLimit值会反映到performanceMax.budget
变更限制为保护广告优化，限制为每个广告系列每2小时1次
创建条件必须设置转化追踪（转化脚本安装完成）且商业频道处于已审核通过状态
资产组创建广告系列时按默认值（全部商品）自动生成 — 商品筛选等设置变更仅可在广告系统（UI）中进行
使用同意如需购物商品联动·站外广告使用同意，将自动完成同意处理
⚠️ 不提供资产组及其下级要素的创建·修改API。资产组仅支持成效查询（参考CH 7）。

7 成效查询API (Performance API)

成效查询层级

查询层级 
素材层级   : 广告账户 → 广告系列 → 广告组 → 素材
资产组层级 : 广告账户 → 广告系列 → 资产组    ← ADVoost购物（PMAX），2026.08.26 新增

系统提供按查询单位的下级要素汇总的结果。（例：广告系列的历史成效按广告组·素材或资产组单位汇总）

三种查询类型

类型路径主要参数
历史成效/performance/past/{aggregationType}startDate、endDate、timeUnit(daily/hourly)、limit、next
实时成效/performance/realtime/creatives
/performance/realtime/assetGroups		targetDate(today/yesterday)、since、timeUnit
转化成效/performance/conversion/past/…
/performance/conversion/realtime/…		同上 + 转化指标

历史成效的aggregationType：campaigns · adSets · creatives · assetGroups（2026.08.26 新增）

实时成效可将响应中的until值用作下次请求的since，实现增量查询。

主要响应指标

字段含义
sales广告费（消耗金额）
impCount / clickCount / vplayCount展示数 / 点击数 / 视频播放数
convCount / convSales转化次数 / 转化销售额
targetDate / hour成效发生日期 / 时段（仅按小时查询时包含）
campaignNo / adSetNo / creativeNo / assetGroupNo汇总单位ID

按资产组单位查询一般成效时，vplayCount始终返回0。

按广告账户提取消耗金额

没有可一次性返回账户单位合计的端点。由于汇总单位(aggregationType)中没有adAccounts，标准做法是以广告系列单位调用广告账户端点后合计sales。

bash / curl 
# 1) 查询我的广告账户列表
curl -X GET 'https://openapi.naver.com/v1/ad-api/1.0/adAccounts' \
  -H 'Authorization: Bearer {访问令牌}'

# 2) 按账户以广告系列单位·按日查询历史成效 → 合计 rows[].sales
curl -X GET 'https://openapi.naver.com/v1/ad-api/1.0/adAccounts/456/performance/past/campaigns?startDate=2026-09-01&endDate=2026-09-10&timeUnit=daily' \
  -H 'AccessManagerAccountNo: 123' \
  -H 'Authorization: Bearer {访问令牌}'

# 3) 账户较多时，遍历 1) 的列表并重复调用 2)
⚠️ 基于成效的消耗金额(sales)与结算·账单金额可能不同。账户余额·充值·退款、税务发票等结算信息查询API并未提供。结算口径金额需在广告管理平台（UI）中确认。

详细的请求·响应规格请参考官方文档的成效API规格说明。

8 潜在客户管理API (Custom Target)

客户文件定向

  • 通过上传广告标识符(adid)列表来注册·修改客户文件定向，可添加·移除部分adid
  • 已注册的客户文件可作为广告组的潜在客户定向使用
  • 可注册回调URL以追踪有效性检查·上传结果
项目限制
单次上传容量最大100MB
累计容量最多可追加至600MB
上传超时20秒
重复请求在分析完成前，不可对同一adidLibraryNo重复请求

9 运营参考 & FAQ

常见问题

  • 认证错误：请先确认访问令牌的过期/有效性、以及服务使用条款的同意时点问题
  • 响应字段含义：在各API菜单中确认响应字段说明
  • 管理账户权限：向管理账户下属广告账户发起请求时使用AccessManagerAccountNo头
  • 可以提取各账户的消耗金额吗？可以。但由于没有账户单位的合计端点，需按广告系列单位查询后合计sales。结算·账单金额查询API仍未提供。
  • ADVoost购物也能通过API运营吗？可以。自2026年8月26日起支持广告系列创建·管理(PMAX)及资产组单位成效查询。但资产组本身的创建·修改仅可在UI中进行。
